PinShot fictional matching sample / PinShot 虚构匹配示例

Requires GPX import in PinShot 1.3 or later.
需要 PinShot 1.3 或更高版本的 GPX 导入功能。

This is synthetic test data, not a recorded trip or a real travel photo.
这些是人工构造的测试数据，不是真实行程或旅行照片。

1. Unzip this package. In PinShot, open Settings or Tag > Import GPX track.
2. Select pinshot-demo.gpx. Review the time range and import it.
3. Add pinshot-demo.jpg to Photos, then manually select it in PinShot Tag.
4. Geotag the sample and inspect its location. Its original EXIF capture time is
   2026-11-01 02:01:00 UTC, inside the sample track. Set camera clock offset to 0
   for this sample; note your previous offset first and restore it afterward.
5. The expected interpolated position is approximately 35.659000, 139.746150.

1. 解压示例包，在 PinShot 的“设置”或“标记”页面选择“导入 GPX 轨迹”。
2. 选择 pinshot-demo.gpx，检查时段后导入。
3. 将 pinshot-demo.jpg 加入系统“照片”，再在 PinShot 中手动选择。
4. 标记后检查位置。图片原始 EXIF 时间是 2026-11-01 02:01:00 UTC，位于
   示例轨迹内。测试时将相机时间偏移设为 0；先记下原偏移，完成后恢复。
5. 预期插值位置约为 35.659000, 139.746150。
