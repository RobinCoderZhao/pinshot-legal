One small trip. Four clear steps.

Start with a few supported photos and their corresponding track. You can check the match before changing any media.

  1. 01

    Bring your GPX

    Export the recorded trip from your existing logger. Keep a copy. PinShot reads GPX 1.0/1.1 track points with valid timestamps; a planned route without times will not work.

  2. 02

    Check before importing

    Open Settings or Geotag → Import GPX track. Review the map, time range, points and skipped items, then confirm. The imported source stays separate from your other recordings.

  3. 03

    Match the camera clock

    Preview a capture time inside the track. Check the camera clock and time zone. The calibration assistant changes the matching offset; it does not rewrite photo dates.

  4. 04

    Tag a few, then inspect

    Select a few matching photos and run geotagging. Inspect the resulting locations and media before processing a larger batch. On iOS, review tagged copies before manually cleaning up originals.

Do I need Pro to import GPX?

No. GPX import and the read-only time-match preview are available without Pro. The free monthly allowance is 20 media geotags. Pro adds unlimited tagging, full/custom-date scans, Mac folder tagging, exports and optional personal iCloud log sync.

Will every exported GPX work?

No universal compatibility is promised. The file needs recorded track points with valid timestamps. Start with one short trip, review skipped points and gaps, and verify a few photo locations.

Can Mac record the route for me?

Mac imports or syncs recordings; it does not act as a mobile GPS recorder. Use PinShot on iPhone or another recorder before shooting.

What if the location or file result is wrong?

Check the selected source, original capture time, time zone and camera offset. Keep original-file backups. A skipped or failed item is not a successful geotag. Contact support with the app version, file format and error text; private trips or photos are not needed for a first report.
